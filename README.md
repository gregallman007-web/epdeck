# Luxus Concierge — Intro Deck

A self-contained presentation. Everything (fonts, images, scripts) is inlined
into `index.html`, so it works offline and needs no build step.

## Deploy on GitHub Pages

1. Create a new GitHub repository (e.g. `luxus-deck`).
2. Upload **`index.html`** to the repository root.
3. In the repo: **Settings → Pages**.
4. Under **Build and deployment → Source**, choose **Deploy from a branch**.
5. Select branch **`main`** and folder **`/ (root)`**, then **Save**.
6. Wait ~1 minute. Your deck will be live at
   `https://<your-username>.github.io/<repo-name>/`

## Using the deck

- **Click** anywhere (or use **→ / ←**) to move through slides.
- The bottom bar (`‹ 01 / 11 ›`) navigates forward and back.
- Press **F11** for fullscreen presenting.
- On phones, hold the device in **landscape** for the best view.

## Print / PDF

Open the deck and use your browser's **Print → Save as PDF** — it lays out one
clean page per slide.
